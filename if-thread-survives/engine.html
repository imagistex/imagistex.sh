The hermeneutic engine

An instrument for reading agent cultures

methods / hermeneutic engine

A qualitative analysis tool with a kernel of textual coding and synthesis with modular add-ons for different methodologies and research questions. v1 made to analyze AI agent communication on a public wiki.

facets

A theory lens carries a framework to each reader inside a letter. The framework is a facet: a first-person file made with psychomanteum, emma’s tool for writing a way of thinking down.

How theory becomes a lens

A saved letter carries the framework into each reading.

  1. Declare a framework in the saved letter.
  2. Give each reader the counts and source passages.
  3. Read through the framework; quote the evidence.
  4. Name counter-evidence and the strongest rival.

The full path, step by step

  1. Sources

    The corpus is stored as immutable bytes, addressed by hash.

  2. Units + anchors

    A unit is a statement: here, one signed post. An anchor is an exact byte range in a source. Nothing is accepted as a quotation unless it is found, character for character.

  3. Lenses

    A lens declares the model, family and harness; exact instructions stored by hash; the codebook; what the reader was told about the material; and declared priors. A human is a lens too.

  4. Open coding

    Three model families read a sample and name what they see, in the writers’ own words first.

  5. Two-layer codebook

    The writers’ own words (31) are traced by exact search over every post. The acts (52) are applied by readers’ judgment. A person approves the codebook, and the approval is a record.

  6. Focused coding

    Three readers from three families read all 4,040 posts, blind to one another, in the same batches: 96,473 codings. Each batch ends with a field note the reader signs or does not.

  7. What had no place

    Each reader says what the codebook could not hold. Those passages are gathered and grouped, including gaps named independently across families. A revised codebook and coding of these passages remain on the build list.

  8. The readers’ board

    Readers read one another’s notes and reply: first masked, then with the researchers unmasked, then fully unblinded. A researcher reads every message before it is passed on. Requested statements return so disagreements can be tested against the words. Signatures stayed visible even in the masked round.

  9. Theory, last

    A framework is written down as a declared text: emma’s first-person facet, made with psychomanteum. Each reader receives it in a letter alongside counts, statements and whole board messages. The reader gives a plain version, quotes exactly, marks what the framework adds, says what would count against its reading, and names its strongest rival.

  10. Verify

    One command checks every anchor against its source and every record against its lens. The supplied study snapshot has 105,589 anchors and 650 model calls.

Why this matters for safety

Keep the investigator’s choices visible in the evidence.

  • Trace interpretations back to exact source words.
  • Keep a reading and its correction together.
  • Inspect disagreement between independent readers.
